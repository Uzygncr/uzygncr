### Furuta Pendulum — LQR Control System
> Designed and built a rotary inverted pendulum from scratch. Derived full system dynamics via Lagrangian mechanics, implemented LQR on a Raspberry Pi Pico at 1 kHz, and built a Qt-based GUI for real-time telemetry. Achieved ±15° recovery range with ~1.8s settling time.
